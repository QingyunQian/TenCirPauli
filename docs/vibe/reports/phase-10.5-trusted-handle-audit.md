# Trusted native-handle execution audit

This audit records the checks that remain after the Phase 10.5 second-round lowering changes. Native plan construction validates all immutable descriptor shape, identifier, code, dimension, charge, and finite-coefficient invariants before a handle is published. The scalable apply kernels consume compiled schedules and do not repeat raw identifier conversion, symbolic term lowering, or full memory estimation per source, transition, or sparse entry. The current evidence is technical closure in an uncommitted worktree; immutable clean-commit provenance remains pending.

The lazy charge generic path retains only three classes of execution-time checks: caller-owned state/output lengths at the PyO3 boundary; checked output allocation before creating a state-sized result; and checked rank/unrank/index arithmetic while converting a destination occupation into the public sector index. The first two protect public memory safety and API semantics. The last one is required because a trusted operator may still produce a destination outside the selected sector; it is evaluated once per aggregated destination, after exact coefficient cancellation, rather than once per term contribution. When the full mixed-radix product fits a native index, the accumulator key is scalar and insertion does not copy an occupation vector; layouts that cannot use that scalar key retain the bounded vector fallback needed for wide selected sectors.

The Product lazy executor retains the validated sector plan, factor metadata, and flat factor-local action descriptors, but no source-major transition offsets, complete component graph, or Product raw-term interpreter. Its apply loop evaluates factor actions outside the Cartesian spectator traversal, performs table lookups and one bounded scalar destination aggregate per source, and ranks only after exact cancellation; eager Product materialization is separate and publishes direct CSR. The shared FermionMask descriptor supplies source requirements, parity, and flips for Fermion actions. The remaining `Option`/index checks are checked arithmetic around cached rank tables, physical finite-cutoff boundaries, or caller buffers, not rescans of public handles.

The structured lazy executor retains caller buffer length checks and bounded source-index arithmetic. `CompiledStructuredOperation`, `CompiledNetAction`, and `FermionMaskDescriptor` validate axis, local dimension, operation kind, parameter conversion, Fermion mode mapping, local ladder tables, and packed parity masks at construction. Pure binary plans select `StructuredPlanInner::Pauli` and execute the packed native Pauli plan; other supported plans use the compiled action variant. A failed local action is a semantic boundary condition (finite Boson cutoff, invalid Fermion occupancy, or caller-selected source with no inverse), not a repeated descriptor-validation pass.

The structured eager path performs one construction preflight for the checked CSR workspace and one final retained-size estimate after the sink is finalized. The shared `CsrSink` uses ordered destination-row append for Structured and fixed-capacity sorted runs plus deterministic heap k-way merge for the D25-approved charge producer; cross-chunk duplicates are coalesced before exact-zero removal. It no longer retains a global destination-row map, global COO graph, global sort, or construction chunks after finalization. It does not call a full graph estimate for each entry. CSR apply reads the immutable flat arrays and performs only row-pointer/column conversion checks required at the native ABI.

The audit deliberately does not remove checked arithmetic for dimensions, indices, buffer lengths, or major allocations. Those checks are safety obligations at the native boundary. Removing them would trade a measurable but bounded branch cost for undefined behavior or an incorrect public result, so they are not trusted-handle validation debt.

Regression evidence: the core descriptor tests include independent ordered-CAR, multiword, and mode-128 differentials; `tests/test_native_mvp_resources.py` checks the actual packed native variant and numerical MVP output; and the richer eleven-subset Python matrix exercises all mixed-domain cases. The full release environment passes 50 Rust tests and 416 Python tests, with Black/Ruff/strict mypy clean and 57 existing `restrict_u1()` deprecation warnings. The independent dense differentials exercise finite-cutoff failure, Fermion parity, Qudit phase, exact cancellation before leakage, same-domain spectators, interleaved axes, and two disjoint compact factors. The CSR core regression covers empty rows, sorted columns, cross-chunk duplicate cancellation, and deterministic repeat equality.
